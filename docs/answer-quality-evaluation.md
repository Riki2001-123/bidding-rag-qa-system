# 问答质量 V2 — EVALUATE

日期：2026-10-06。依据 [SPEC](answer-quality-spec.md)。结论：政策原文输出和指定格式追问的针对性本地验收通过；未完成全量问答质量、法律时效或生产交付认证。

## 实现

单领域政策 RAG 先把授权原文的完整条款编号，由现有模型选择整数编号，程序提取原文并核验来源和边界后输出。引用增加实际使用的 excerpt。格式追问只选择上一轮实际引文；新的政策问题重新检索。后端重启从持久化引用恢复并重新检查权限。旧引用没有 excerpt 时兼容读取授权原文，不表示旧模型回答已经验证。

会话在生成前 flush 获得 ID；完整答案保存后才发送 done。取消、生成失败或保存失败回滚并清理会话内存缓存。演示数据与真实 API 仍独立。

## 初次失败及修复

- 模型直接复制原文时改动空格，真实引文被严格拒绝；改为条款编号。初次 passage 字段仍被模型当作文本，收紧为整数 passage_id 后复测通过。
- 只限制同一来源文件时，追问曾选入该文件第八条信息发布规定。收紧到上一轮实际 excerpt 后，最终真实复测和自动检查确认不引入新条款；此前报告不计为这项通过。
- 跨域单测的模拟数据库缺少授权政策原文，更新夹具后回归通过。
- 扩大旧 smoke 测试时长时间无进展，已终止且未计为通过，阻塞原因未定位。本次只声明表内明确运行的检查。
- 首次网页复测在服务重启窗口未进入检查，已停止；加入健康等待后最终 6 项通过。

## 未验证与边界

- 政策模式输出原文，未做自由语义概括；最多保留要求的条数，不能保证一定有两点。逐字匹配不能证明对所有问题都相关或为现行版本。
- 每份原文上下文最多 2400 字，截断涉及的未完成条款排除；后部条款可能未进入模型。没有全量召回、回答质量指标。
- 招标/企业结构化、跨领域、ReAct 回答未统一到这套原文约束，没有认证这些路径的全部事实推断。
- 真实数据缺少附件及 private/internal 权限样本。权限撤销和外部用户会话由隔离单测覆盖，实际附件及这些权限组合仍未验证。
- 未主动制造真实模型供应商故障；异常、中断和保存失败用模拟与事务测试。并发、负载、公网部署和账号隔离治理未验收。
- 本机 CPU 首轮检索仍较慢：终轮原问题约 65 秒，格式追问约 1 秒，仅为受复测环境影响的小样本记录，不用于性能宣传。非空筛选旧路径的大索引风险仍见上版评估。

在项目根目录执行，使用已有 MySQL、Milvus、模型配置，会新增测试问答：

```powershell
$env:TEMP = "$PWD/dist"
$env:TMP = $env:TEMP
$env:PYTHONDONTWRITEBYTECODE = '1'
& ./backend/scripts/start_local.ps1 -LogDirectory "$PWD/dist/answer-quality-tests"
python ./backend/scripts/check_answer_quality.py
# 按 real-qa.json 中的 session_id，重启本机后端后运行：
python ./backend/scripts/check_answer_quality.py --restore-session <session_id>
```

frontend 下执行 npm run test:quality；PLAYWRIGHT_MODULE_DIR 指向已有 Playwright 包，默认已安装 Edge。TEMP/TMP 保持 D 盘。可用 RAG_TEST_USER / RAG_TEST_PASSWORD 指定测试账号，报告不记录令牌。下一版建议已写回 SPEC。
